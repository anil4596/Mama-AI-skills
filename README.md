# Mana AI Skills

A free Telugu-first beginner learning web app for practical AI skills.

## Live website
https://anil4596.github.io/Mama-AI-skills/

## Current features
- Six beginner lessons in Telugu
- A quiz for each lesson
- Search lessons
- Progress tracking saved in the current browser using localStorage
- Responsive layout for mobile and desktop
- No account or payment required

## Publish updates
The site is hosted with GitHub Pages from the `main` branch and repository root.

## Current limitations
- Progress is stored only in the same browser/device
- No user accounts, cloud sync, certificates, payments, or ads
- This is a learning prototype; review the course content before commercial use
